# 일반 한국어 앱의 배포 소스 통합

2026-11-11에 `jaimeen77-cmyk/apps`에 잘못 등록되어 있던 일반 한국어 앱 15개를 `appsKOR`로 옮겼습니다. `apps`에서는 Circuit과 Cluster Redline의 한국어·영어판만 제공합니다. `appsKOR`에서는 일반 앱 15개와 기존 클러스터 앱 3개, 총 18개를 제공합니다.

이동 대상의 사전 컴파일 파일은 기존 `appsKOR`보다 최신이므로, 앱 이름만 숨기는 대신 최신 목록·아이콘·완성된 패키지 레이어를 함께 옮겼습니다. `store/migrations/apps-2026-11-11.json`에 원본 저장소 커밋, 버전, 소스 입력 해시, 레이어 해시와 전체 패키지 내용 해시를 기록했습니다.

## Store에서 확인

- `jaimeen77-cmyk/apps`와 `jaimeen77-cmyk/appsKOR` 소스의 `main` 브랜치를 새로고침합니다.
- 일반 앱은 `appsKOR`에서 설치·업데이트합니다.
- Circuit과 Cluster Redline은 `apps`에서 설치·업데이트합니다. 일반 `redline`과 별도 앱 `cluster_redline`은 다른 앱입니다.

저장소 목록 정리는 이미 차량에 설치된 앱이나 별도 ID(`redline2` 등)의 복사본을 자동 삭제하지 않습니다. 차량의 Installed 목록에서는 앱의 ID·소스를 확인해 사용하지 않는 항목을 구분해야 합니다.

## 런타임과 재생성

새 일반 앱 15개는 새 공통 레이어를 사용합니다. 기존 클러스터 앱 3개는 원래 공통 레이어를 `store/korean/common-<전체 SHA256>`에 보관하여 기존 패키지 파일을 그대로 유지합니다. 설치 도구는 앱 레이어가 기록한 전체 해시로 맞는 공통 레이어를 선택하고 크기·체크섬·경로를 검증합니다. 임의 런타임으로 대체하지 않습니다.

이동한 앱의 설치 원본은 검증된 `store/korean` 레이어입니다. 저장소의 `apps/` 아래 유지보수용 소스는 그보다 이전 커밋일 수 있습니다. 최신 컴파일 파일의 출처는 이동 기록의 `source_commit`·`source_hash`입니다. 로컬 소스로 다시 생성하려면 먼저 해당 소스를 새 버전에 맞춰 갱신해야 합니다. 배포 중인 버전보다 이전 소스를 재생성 도구에 넣으면 거부합니다.

`tools/test-korean-store.py --build`는 이동한 15개 패키지의 모든 파일을 이동 전 내용 해시와 대조합니다. 기존 클러스터 앱은 로컬 소스 신선도 검사도 유지합니다. 18개 앱의 실제 조립과 충돌 ID 재할당, 한국어 글꼴·Doom 데이터·SDK 미포함 여부도 검사합니다.
